Одно окно для программ, которые обходят блокировки трафика: **Zapret** (Flowseal), **zapret2** (bol-van) и **ByeDPI** (romanvht). Установка и обновление одной кнопкой, запуск стратегии, автозапуск службой, подбор параметров, режимы DNS, кэш конфигураций на 200 записей с закреплением и удалением.

## Зачем

Обход блокировок — это не «скачал и запустил». Нужна стратегия, которая подходит именно вашему провайдеру; нужен безопасный DNS; нужно обновлять пакет, не потеряв свои списки; нужно понять, почему не работает. Всё это здесь в одном окне, а не в консольных меню и пяти папках.

## Как устроено

- **Вверху** одна строка из трёх кусков: название, по центру три больших переключателя — ZAPRET, ZAPRET 2, BYEDPI, справа язык, тема и шрифт. Переключатель — это полное переключение DPI-инструмента: у каждого свои файлы, подключение и своё значение кнопок UPDATE и START. Версия и «работает ли сейчас» показаны на самих кнопках.
- **Внизу** постоянные кнопки инструментов — CONFIGS, TUNE, DNS, LISTS, ЖУРНАЛ, DIAGNOSTICS, ABOUT — и справа UPDATE | START. Кнопка, которой нечего делать, серая.
- Окно работает с теми же файлами, службами и записями реестра, что и bat-файлы Flowseal, поэтому меню `service.bat` и это окно можно использовать вперемешку.

## Что внутри

| Раздел | Что делает |
|---|---|
| ZAPRET | Установка и обновление пакета Flowseal, запуск стратегии, служба, фильтры игр и IPSet |
| ZAPRET 2 | Установка, обновление и подключение zapret2; пресет из документации в поле |
| BYEDPI | Установка и обновление ByeDPI Manager, подключение через системный прокси |
| CONFIGS | Поле конфигурации и кэш на 200 записей (звёздочка — закрепить, крестик — удалить) |
| TUNE | Подбор параметров: ГОТОВЫЕ, ПОВТОРЫ, ОБМАН, РАЗРЕЗ, ВСЁ |
| DNS | Режимы GOOGLE, CLOUDFLARE, QUAD9, ADGUARD и СВОЙ (серверы и адрес DoH в одной строке) с проверкой и точным возвратом |
| LISTS | Готовые списки для России с GitHub (runetfreedom, itdoginfo, re:filter; обновляются каждый день) для Zapret, zapret2 и ByeDPI, свои списки, импорт и экспорт, список IPSet, файл hosts |
| DIAGNOSTICS | Причины, по которым обход не работает, таблицей и с исправлениями |

## Запуск

Запустите `Start.exe`: Windows спросит права администратора (без них не загрузить драйвер WinDivert). Подробно — в [руководстве](USER_GUIDE_RU.md).

## Что программа не делает

Не собирает и не отправляет данные; обращается только к GitHub (версии, релизы, списки) и, по вашей кнопке, к DNS-серверам, которые вы указали сами. Не ставит ничего в планировщик Windows. Меняет систему только по вашим кнопкам, каждое изменение — в журнал, DNS и системный прокси возвращаются точно.

Сторонние программы (Flowseal, zapret2, ByeDPI Manager) скачиваются с GitHub по вашей кнопке и лежат в своих папках со своими лицензиями.
